## Power BI Premium to Microsoft Fabric migration guidance

I authored this connected four-article set as the project’s knowledge engineer. I drafted the guidance, managed review with subject-matter experts across teams, incorporated successive revisions, refined wording, and filled gaps.

- [Migration overview](https://learn.microsoft.com/en-us/power-bi/support/premium-migration-overview): the end-to-end journey, what changes and stays the same, and migration scenarios.
- [Decision guide](https://learn.microsoft.com/en-us/power-bi/support/premium-migration-decision-guide): timing, capacity choices, and decisions for administrators and architects.
- [How-to guide](https://learn.microsoft.com/en-us/power-bi/support/premium-migration-how-to?tabs=portal): prerequisites, workspace migration procedures, and validation steps.
- [FAQ](https://learn.microsoft.com/en-us/power-bi/support/premium-migration-faq): common questions about timing, purchasing, sizing, and migration behavior.

Together, these articles demonstrate connected technical guidance across a customer journey, cross-team SME coordination, and precision across related content. I did not execute customer migrations or own the product retirement. Read the [full migration case study](../case-studies/premium-to-fabric-migration.md), including the project-level reach and retrieval signals.

## End-to-end Power BI tutorial

I authored the [end-to-end Power BI tutorial](https://learn.microsoft.com/en-us/power-bi/create-reports/tutorial-end-to-end-power-bi). It walks a reader from raw data through transformation, reusable semantic modeling, report creation, workspace publication, and app distribution.

This is useful as an example of making a multi-stage technical workflow learnable: each phase connects a user goal to the tool and decision needed at that point.
